Changes from 1.0.0
------------------
Install pins the Lucide icon set: it loads the icon list and spritesheets from
the icon revision above, caches them in CloverHub/icons-1c37dd1 under unique file names
(clover-lucide-1c37dd1-*.png, because getcustomasset keys assets by file name),
and applies them with Library:SetIconModule before any tab is built. Upstream
icon updates and other scripts' lucide-icons downloads no longer change the hubs.

Dependency note
---------------
This is not a standalone UI bundle. It does not create or download an Obsidian
library. The host passes in an already-constructed Obsidian instance pinned to
revision fa7be5477c30e4a302cc60c85e93ecca926d297b. Obsidian remains a separate
dependency and is not vendored here.

Contains no credentials, tokens, licence logic, game routing or gameplay code.
